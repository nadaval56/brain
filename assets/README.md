# Brain model

`brain.glb` is derived from **Brain for Blender** by Anderson M. Winkler
(https://brainder.org/research/brain-for-blender/), generated with FreeSurfer,
licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

Changes: the cortex was rebuilt as closed solid lobes (voxelised inside the pial surface, labelled by Desikan-Killiany region, smoothed), the
subcortical structures were grouped (e.g. caudate + putamen + pallidum +
accumbens → basal ganglia), and all meshes were decimated for the web.
This derived model is shared under the same license (CC BY-SA 3.0).
